SCP:SL AUTO-JOINER

Open SCP-SL-Auto-Joiner.exe.

Quick start
1. Open the app, then add a saved server or use Remember current server before
   joining normally in SCP:SL.
2. Choose the saved server or retry group on Auto-Join.
3. Use Watch for a slot for the recommended query-first workflow, or Start
   auto-join to begin the Direct Connect flow immediately.

The app stores servers, groups, settings, history, calibration profiles, themes,
text-pack records, reports, and logs in:
%LOCALAPPDATA%\SCP-SL-Auto-Joiner

Watch Mode queries the selected saved server and does not touch SCP:SL until a
slot is confirmed. Immediate Auto-Join works from the SCP:SL client geometry
and observes the game's local connection record for connecting, full/rejected,
and joined outcomes. If Unity requires compatibility input, the app briefly
focuses the game, then restores the cursor and previously focused app.

Set Retry delay to 2 for the normal full-server retry behavior. Set Maximum
attempts or Maximum runtime to 0 for unlimited operation. Stop auto-join from
the app at any time.

If the game layout or display arrangement changes, open Diagnostics and follow
the guided calibration steps. Calibration profiles are local to this computer.

The app does not include SCP:SL or Steam. The game must be installed through
Steam and the user must be allowed to join the selected server.
