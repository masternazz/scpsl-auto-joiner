# Product design

SCP:SL Auto-Joiner is a local-first Windows utility for saved servers,
ordered retry groups, watch mode, calibration, translation packs, and clear
diagnostics. The interface uses a restrained containment-inspired visual
system so operational state remains easy to read.

The application does not require an account or hosted service. User data stays
in the local AppData directory unless the user explicitly exports or shares a
destination bundle.
