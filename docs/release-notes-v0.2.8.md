# SCP:SL Auto-Joiner v0.2.8

### Direct Connect coordinate correction

- Corrects the automatic Direct Connect target to the actual SCP:SL server-toolbar position.
- Prevents the automatic click from landing on the neighboring Rent/Re-Join controls.
- Keeps client-area scaling for 1080p, 4K, borderless, and windowed layouts.

### Disclaimer

This is an early Windows build and has **not** been tested on every SCP:SL server, Windows configuration, monitor resolution, DPI setting, or game layout. Please [report issues on GitHub](https://github.com/masternazz/scpsl-auto-joiner/issues) with your Windows version, display setup, reproduction steps, and app log.
