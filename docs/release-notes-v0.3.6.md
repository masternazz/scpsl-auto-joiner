# SCP:SL Auto-Joiner v0.3.6

## Changes

- Replaced the browser-native reset confirmation with a themed in-app confirmation dialog.
- Added keyboard-safe cancel and Escape handling for confirmation actions.
- Kept the WebView2 shell, saved-server browser, retry controls, diagnostics, translation packs, themes, and local AppData storage.
- Added regression coverage for the confirmation flow across supported desktop viewport sizes.

## Release note

This is an early Windows build and has not been tested on every SCP:SL server, Windows configuration, monitor resolution, DPI setting, or game layout. Please report issues with the app log, Windows version, display setup, and reproduction steps at the GitHub issue tracker.
