## SCP:SL Auto-Joiner v0.2.2

An early Windows build with a rebuilt Servers workspace.

### Changes

- Reorganized Servers into distinct Browse, Edit, and Groups areas
- Moved live retry activity to Auto-Join so server management stays focused
- Automatic warm retries no longer invoke Steam's Game Info dialog
- Added clearer saved-server selection and action labels

### Important disclaimer

This build has **not** been tested on every SCP:SL server, Windows configuration, monitor resolution, DPI setting, or game layout. Bugs are expected. Please report problems through the in-app button or the [GitHub issue tracker](https://github.com/masternazz/scpsl-auto-joiner/issues) with your Windows version, display setup, reproduction steps, and app log.

The portable package must keep the `_internal` folder beside the EXE. The setup installer manages those files for you.
