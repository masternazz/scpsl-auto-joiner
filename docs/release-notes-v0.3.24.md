# SCP:SL Auto-Joiner v0.3.24

## Web interface feature parity

- Restores the important workflows from the legacy interface in the WebView UI:
  saved servers, ordered retry groups, current-connection capture, guided
  calibration, diagnostics, settings, text packs, updates, and onboarding.
- Reworks Auto-Join, Servers, Diagnostics, Settings, Quick Start, and
  Documentation into clearer responsive layouts.
- Adds first-class dark and light appearance modes, curated palettes, semantic
  color controls, sanitized custom CSS, and reset-to-default controls.
- Replaces browser-native prompts with in-app forms and confirmations.
- Preserves existing servers, groups, calibration, settings, themes, and packs
  stored under AppData.
- Keeps the startup bridge hardening introduced in v0.3.23.

- `SCP-SL-Auto-Joiner-v0.3.24-win-x64-portable.zip`

## Reporting issues

SCP:SL client behavior can vary between game versions and display setups. If
you find a problem, create a bug report in Settings and include the app log,
Windows version, resolution, DPI scale, and whether the game was windowed or
borderless.
