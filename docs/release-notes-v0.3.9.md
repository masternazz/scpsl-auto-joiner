# SCP:SL Auto-Joiner v0.3.9

## WebView feature-parity patch

This patch restores WebView controls that were present in the legacy interface but missing from the first WebView releases.

### Changes

- Added advanced compatibility, notification, update, group-loop, and server-refresh settings.
- Added GitHub translation-pack search results with source and install actions.
- Preserved persisted light/custom theme application on fast startup.
- Rebuilt the portable package and setup installer.

### Known limitations

Unity/client behavior can vary by SCP:SL version, display configuration, and Windows setup. Please report issues with the app log, Windows version, display resolution/DPI, and reproduction steps.
