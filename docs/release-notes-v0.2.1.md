## SCP:SL Auto-Joiner v0.2.1

An early Windows build of the SCP:SL Auto-Joiner.

### Included

- Reliable direct-start and warm retry paths
- Saved-server browser with search, names, player counts, latency, and status
- Ordered server groups with retry-in-order and optional looping
- AppData storage, delete/rename controls, diagnostics, calibration, and settings
- Background retry input that leaves the physical mouse available
- Portable ZIP and per-user setup installer
- In-app **Report a bug on GitHub** button in Help

### Important disclaimer

This build has **not** been tested on every SCP:SL server, Windows configuration, monitor resolution, DPI setting, or game layout. Bugs are expected. Please report problems through the in-app button or the [GitHub issue tracker](https://github.com/masternazz/scpsl-auto-joiner/issues) and include your Windows version, display setup, reproduction steps, and app log.

The portable package must keep the `_internal` folder beside the EXE. The setup installer manages those files for you.
