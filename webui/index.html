How it works

A plain-language guide to every button and what the automation is doing.

01Calibrate once

Capture the six SCP:SL controls from the setup page. This is stored per computer, not online.

02Remember a server

Start the watcher, join a server normally, and give the detected IP and port a friendly name.

03Start the queue

Pick a saved name. The app opens the game, enters Direct Connect, and retries rejected attempts.

04What it does not do

No memory reading, packet manipulation, OCR, or anti-cheat bypass. It sends normal Windows input and reads Player.log.
